# Montage联合选词：独立整数重放与电压图审

本次审计完成，但两种新整数模型均未达到原波形与视觉要求。联合选词确实改善一般波形误差、相关和边界连续性，仍未解决S分量幅度不足、S的α能量损失及多个库的大事件消失。模型的正式数值事实源为上级目录`summary.json`；本报告汇总独立重放与实看图所得证据，不更改阈值、样本或原判决。

访问范围为原60名训练被试、四折400个完整原生阵列、17,040个位置窗。各库裁片/位置窗为Single-Trial136/4080、REFED152/9728、Simultaneous80/2240、Visual32/992。无validation、确认或test读取；没有新增训练或重编码。原17个固定/随机/P90/困难身份全部保留；按冻结规则追加每库、每种新arm的联合/S/O宏窗误差最大身份，物理三元组去重后共21个身份。

v8 frozen、semantic64和waveform使用同一冻结K15351字典、空间后验、训练尺度和同一真实波形。semantic64只在当前角色占有码的64个局部属性近邻加原词中联合搜索，waveform搜索同角色全部占有码；两者都仅传输每原生位置每分支每2秒一个14位整数。每位置每分支7bit/s；整个17040位置窗每arm共511200个整数，7156800bit，整阵列连续打包下最小894600byte；逐30秒数组打包的末字节零填充另计在`transport_review.json`。无附加逐窗均值、尺度、相位或连续latent。

独立实现14位pack/unpack和整数原子查表，再调用冻结后验合成；解码函数参数仅含整数、冻结书和冻结state，未调用编码器或source。每库每折前三路另做禁止外部文件读取的解码探针。全部400阵列、三路、X/S/O的原主指标及动态指标与生产held评分逐数组bitwise一致。另从原mask下的逐点误差、各目标冻结训练方差直接复算NMSE及原单位RMSE；不是用当前窗方差重归一化。

这些S最坏窗的峰时多数仍接近，但幅度仅约23%–37%；ST和Sim的完整X可较接近而S峰严重不足、O对应峰偏大，直接显示总和重建不能证明分量恢复。原困难REFED FC2的0秒裁片X大负峰同一时刻仅恢复4.89%，Sim CP5振荡爆发X峰5.46%，Visual S11大双相X峰12.86%；补图将这些实际电压放大到2秒及边界，确认持续动态及幅度均未恢复。ST保留的持续大载波困难成员完整展示，不删除或改变其频带/掩码合同。新选词显著减轻该窗v8 S中每2秒出现的假脉冲，这是局部收益，X/O的大载波失败也同时保留。

`case_amplitude_timing.csv`保留189个identity×branch×arm的原单位RMSE、RMS增益、真峰时刻与幅度、同一时刻预测比值及±0.5秒内预测绝对峰的时差。该时差是局部峰诊断，不能解释为神经事件时延。列`RMSE_native_in_true_S_peak2s_window`统一在图示S峰附近2秒计算，X/O也沿用同一窗；完整窗评价保留原mask。原生50Hz尾部的波形与1–45Hz动态评分分开呈现，图中没有平滑、独立缩放预测或隐藏尾部。

每个身份的实看图问题记录、路径和选择理由见`actual_image_review.json`及`figure_manifest.json`，入口`index.html`逐身份并列。所有冻结原ID、增加的困难身份及错误分布均保留。此审计没有对实际新词的单ID增量作判断；词义由父任务的纯折fit/held读出另行核验，不能用本组更好的序列重建或漂亮个例替代。

计算由user systemd持久运行，原重放/绘图252.618654 CPU秒，五张X事件补图15.094186 CPU秒，共267.712840 CPU秒（4.462分钟），低于20CPU分钟。4worker、BLAS/OMP/MKL各1线程，主审计14GiB、补图8GiB上限，无GPU，两个作业MainPID均为0，未改变主producer或全局registry。资源、命令和软件快照均在本目录。两项transport/独立lookup测试通过，pytest collect3576/3587（11 deselected），git diff --check通过。

结论：冻结整数接口与独立重放通过；一般波形和边界误差有实证收益；S幅度/α动态及多库困难事件仍未通过。维持训练阶段失败判决，本组不协调进入开发或确认。恢复入口为本目录`launch.json`中的全量命令；补图入口为同脚本`--stage X-events`，冻结规则在`audit_config.yaml`。
